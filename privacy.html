Crucilux · Privacidad

Política de privacidad

Crucilux está diseñado como una aplicación web sencilla que funciona directamente en el navegador.

Datos y almacenamiento

La versión actual no requiere crear una cuenta, no utiliza una base de datos remota para el progreso y no incorpora publicidad ni sistemas propios de seguimiento.

Para permitir que una persona continúe el reto inicial después de recargar, Crucilux conserva localmente mediante localStorage las palabras ya resueltas, la pista activa y el mejor resultado alcanzado. La estructura también incluye una versión interna del formato guardado.

Estos datos permanecen en el navegador y no se envían a una base de datos de Crucilux. Si el almacenamiento local no está disponible o no puede utilizarse, el reto continúa funcionando durante la sesión sin persistencia.

Retención y reinicio

El botón Reiniciar borra las palabras resueltas de la partida actual y vuelve a la pista inicial, pero mantiene la mejor marca histórica. Si no existe una partida ni un mejor resultado, Crucilux no necesita conservar un registro local.

La persona usuaria también puede eliminar estos datos borrando el almacenamiento del sitio desde la configuración de su navegador.

Información personal

Crucilux no solicita nombre, correo electrónico, ubicación, contactos ni otros datos personales para utilizar sus funciones actuales.

Servicios externos

El sitio se publica mediante GitHub Pages. El acceso al repositorio de GitHub o a otros enlaces externos queda sujeto a las políticas de esos servicios.

Cambios futuros

Si futuras versiones incorporan cuentas, sincronización en línea, analítica, servicios externos o nuevas formas de tratamiento de datos, esta política se actualizará antes de habilitar esas funciones.
