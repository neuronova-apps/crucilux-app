# Plataformas de Crucilux

La página web de Crucilux funciona como acceso oficial y presentación del producto dentro del ecosistema NeuroNova Apps. No sustituye a la aplicación Android ni a la versión de Facebook Instant Games.

## Web

- Estado: disponible.
- Función: acceso web oficial y demostración del producto.
- URL: https://neuronova-apps.github.io/crucilux-app/

## Android / Google Play

- Proyecto Android: existente.
- Estado: en desarrollo y preparación de distribución.
- Enlace público de Google Play: pendiente.
- Cuando exista una ficha pública en Google Play, el enlace debe registrarse en `platforms.json` sin cambiar la URL de acceso web.

## Facebook Instant Games

- Plataforma contemplada: sí.
- App ID de Meta: `28056922780642646`.
- Enlace público para jugar: pendiente de confirmar.
- El enlace público debe dirigir al juego accesible para usuarios y no al panel de desarrolladores.
